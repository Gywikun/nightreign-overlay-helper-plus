# 常见问题与恢复步骤

适用于 r4。先看[图文使用指南](使用指南.md)。判断扫描是否结束，看文字状态和更新时间。

## 下载后 EXE 无法启动，或提示缺少运行库？

下载完整 `win64.zip` 并全部解压。EXE 与 `_internal` 必须在同一目录；只下载独立 EXE 不够。不要从 ZIP 预览中运行，也不要只移动 EXE。仍无法启动时记录完整错误文字和附件来源。

## 是不是每局都要手工截图或点击使用？

通常不用。开局前启动助手，DAY 提示可见时尝试自动计时，完整地图缩到最小后尝试自动识别。只在自动定位失败时使用备用框选；第一次扫描必须等到结果状态后再关图。

## 为什么一直等待、没有地图信息？

1. 主设置中确认“启用地图识别”开启。
2. 关闭设置，切回游戏前台，使用窗口化或无边框窗口化。
3. 显示完整地图、缩到最小，移除遮挡并等画面稳定。
4. 通过托盘“自动运行与检测自检”查看窗口和“完整地图”区域状态。
5. 长期未定位时，使用对应模块“备用：2 秒后截屏框选”，按[校准步骤](使用指南.md)保存区域。

默认两次扫描至少间隔 5 秒，短暂等待不一定是故障。

## 关图太早、切出游戏或扫描失败怎么办？

本次结果可能被拒绝。有缓存时保留上次信息，回到完整地图后可继续显示并查看更新时间；关图、放大局部地图或切出游戏时，标注会隐藏。没有缓存时不显示本次预测。回到完整地图并保持前台，至少等 5 秒再重试，必要时点“立即请求重新识别（备用）”后切回游戏。扫描超过 15 秒的结果不会采用。

## 为什么点“立即请求重新识别”没有立刻更新？

这是排队请求。设置窗口打开时，游戏通常不在前台；请关闭设置、切回完整地图，满足画面稳定和扫描间隔后才会执行。r4 按钮下方会显示已提交、已收到，以及等待游戏前台、区域定位、完整地图、画面稳定或扫描间隔的原因。绿色完成或黄色候选文字出现前，不把按钮点击当成成功。

## 扫描一次以后永远不会再扫描吗？

会根据需要更新。同一局重新开图默认先复用缓存；持续开图达到默认 20 秒刷新周期、画面明显变化、第二天计时开始、人工请求等情况会更新。关闭地图的时间不计入开图刷新周期。

如果每次开图都想强制重扫，可开启“重新开图时强制刷新（通常无需开启）”；日常保持关闭。更新期间保留旧标注，新结果通过检查后替换。

## 黄色提示代表什么？显示的还是旧信息吗？

看文字区分。“候选接近，显示共同信息”表示多个相近候选的共同内容；“本次更新未采用，保留上次信息”表示本次失败，仍显示旧缓存。请核对“几秒前更新”，不要只凭颜色判断。

## 新局仍显示旧地图，或错过 DAY 开局提示？

确认已经进入新局时，在“计时纠正”点“开始新局：清理旧地图和计时，开始第一天”。若已经处于当天中途，选择真实当天/阶段并填该阶段已过秒数，再应用修正。不能从缺失或被遮挡的 DAY 提示推断准确开局时间。

“重置缩圈”快捷键沿用原版的天数切换逻辑，不等同于随时清空新局；需要明确清理时使用上面的新局入口。

## 重启助手后为什么又要识别？

地图缓存仅保存在内存，退出程序后不会保留。设置和校准信息保存在 `%APPDATA%\nightreign-overlay-helper-plus`，原版配置目录保留。

## 放大地图后标注为什么消失？

当前只展示标准完整地图的标注，缩到最小时才识别/显示。回到完整地图可复用同一局缓存；局部地图随缩放跟踪尚未实现。

## 想静音，或觉得弹窗停留太久？

“关键提醒”页关闭“播放提示音”或降低音量。“弹出提示停留时间”调文字时长，和声音长度是两回事。r3 声音约 0.2 秒，文字默认 3.5 秒；缓存复用/普通刷新不重复响铃。

## 自检没有 DAY/血条预览，是否坏了？

DAY 提示只在对应时刻出现，平时等待正常。切出游戏后也没有新预览。返回游戏并让相应区域可见再判断；主设置的游戏语言应与实际一致。HDR 与特殊 UI 比例仍需要实机反馈。

## 程序内帮助与网页指南是否一致？

r4 已更新自动计时和地图识别帮助，优先介绍自动定位、缓存与后台刷新，并提供完整图文指南入口。旧 r3 的部分帮助仍是原版手动流程，建议升级 r4；备用框选只在自动定位失败时使用。

## 没找到设置、想关闭程序？

从 Windows 托盘图标（含隐藏图标区）右键打开“设置”或“自动运行与检测自检”；右键悬浮计时器也可打开菜单。设置窗口关闭后助手继续运行；托盘“退出”才结束程序。

## 地图预测会自动随游戏更新吗？

不会在线更新地图数据库。资源与计时参数来自上游 v0.10.5。绿色完成表示通过当前检查，不能保证每个预测准确；新的游戏版本或地形变化需要反馈后核实。

## 仍然无法解决？

在[问题反馈入口](https://github.com/Gywikun/nightreign-overlay-helper-plus/issues/new/choose)提供版本、画面设置、复现步骤、当前状态及自检截图。可以从主设置“打开日志位置”取得相关日志；模板会列出需要的信息。
