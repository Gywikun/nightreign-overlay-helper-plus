## 应优先改的程序界面问题

| 优先级 | 问题与证据 | 建议行为 |
|---|---|---|
| 高 | 内置帮助仍要求先手工框选，并称首开识别后到下个 Day1 不再扫描；`src/ui/settings.py` 的自动计时和地图帮助是上游流程 | 改成“默认自动定位 → 失败备用校准 → 缓存与后台更新”，帮助入口直接提供当前指南 |
| 高 | “立即请求重新识别”提交命令后没有单独的点击确认；`src/ui/enhancements.py` 自动页 | 显示“请求已提交，切回完整地图”或具体等待原因，防止用户反复点击 |
| 中 | 网站名称已改为地图信息助手；`src/common.py` 的程序名仍是“黑夜君临悬浮助手 · 自动增强版” | 下一次程序构建时统一窗口、托盘、关于页面名称 |
| 中 | 主设置“启用地图识别”和增强页“启用地图自动刷新”分散；05 截图与 01 截图 | 显示总开关关联状态，明确自动刷新开关不控制所有识别请求 |
| 中 | 05 主设置在 760 逻辑像素宽度时部分警告文字被截断，本次改用宽窗口截取 | 改善小窗口和显示缩放下的换行、滚动与最小尺寸；无需用户依赖放大窗口读完 |

| 待验证 | 源码中的手动“显示/隐藏信息”可能被下一轮自动显示覆盖 | 先复现，再决定是否持久保存用户显示偏好；当前不承诺持续隐藏 |

## 截图能确认和不能确认的事

可以确认当前控件、说明文本、默认值与状态显示。状态同时有颜色、文字和更新时间，用户不必只凭颜色判断。自检下部需要滚动，窄主设置有文字布局风险。

仅凭截图不能证明键盘/读屏完整可用、所有显示缩放下的布局正确、实战识别准确率或物理设备听感。本次也没有验证完整游戏对局、HDR、多显示器和特殊界面比例。
