# 黑夜君临地图信息助手：自动增强版

首次使用请先看[图文使用指南](docs/使用指南.md)、[常见问题](docs/常见问题.md)和[界面截图](docs/界面截图.md)。下文保留增强版详细行为说明。

基于 NeuraXmy 的 nightreign-overlay-helper v0.10.5（a7d4d6838a17f08f532e84273036dbab4f3cbd7c），原项目：
https://github.com/NeuraXmy/nightreign-overlay-helper

本地增强版本：0.10.6+auto.4（r4）。保留原作者署名、资源说明和 AGPL-3.0 许可证。

## r4 界面修复

内置自动计时与地图帮助已改成增强版流程。刷新按钮立即显示请求已提交，后台状态显示已收到、等待条件、扫描或结果。窗口、托盘与关于页面统一使用“黑夜君临地图信息助手”。原配置目录继续沿用。

## 启动

完整解压 r4 发布包，双击 `NightreignHelper-Auto-r4.exe`。保留同目录的 `_internal` 文件夹。
游戏请使用窗口化或无边框窗口化模式。首次打开会显示自动运行设置，关闭设置后即可正常游戏。

## 默认的自动工作方式

- 游戏在前台时，尝试从屏幕定位 DAY 提示、血条和完整地图。定位结果会保存。
- DAY 提示连续检测到后开始计时；同一个提示持续显示时只启动一次。
- 新局开始时清理旧地图、雨中冒险、绝招和提醒状态。
- 打开完整地图后等待画面稳定，再识别地图并显示信息。
- 同一局重新开图直接显示已识别结果，默认不重复扫描。地图明显变化、人工请求或持续开图到达 20 秒周期时更新；关闭地图的时间不计入刷新周期。
- 两次地图识别至少间隔 5 秒。识别不足时等待并重试。
- 多个候选相近时，优先显示它们共同的地点和预测信息；不同的预测会被省略。
- 关图或放大到局部地图时隐藏标记，回到完整地图后复用缓存。局部地图跟随缩放尚未实现。
- 检测区域按 HUD 的左侧、右侧和中心位置跟随窗口移动及尺寸变化。
- 自动取样正常或雨中的血条颜色；手动指定的颜色优先保留。
- 缩圈前 30/10 秒、雨中设定时限前 10 秒、绝招效果结束前 3 秒提示；声音与时间可以修改。
- 切出游戏后继续计时，停止触发新的游戏提醒和画面检测。

## 地图缓存与扫描提示（r4）

悬浮计时器和地图右下角均显示状态：灰色等待、蓝色首次扫描或后台刷新、绿色已识别或复用缓存、黄色候选接近或保留上次信息。
同一局的旧标注在后台刷新期间保持显示；新结果通过检查后才替换。更新失败或扫描中途关图时，不采用本次结果，并保留上次已识别信息。
新局开始会清理旧缓存；确认切换到不同地形时也会清理。缓存仅保存在内存，关闭程序后需再次识别。

地图首次识别结束会提示。缓存复用和普通后台刷新不重复弹出或响铃；保留的缓存会注明上次更新时间。
声音改为约 0.2 秒的柔和短音，默认音量 20；文字弹窗保持原来的 3.5 秒。音量、静音和文字弹窗时长可以调整。
首次无缓存时请保持完整地图打开直至识别结束。关图、缩放、切出游戏、画面明显变化或扫描超过 15 秒时，本次更新结果不会采用；失败后至少等待 5 秒重试。
从 r2 升级时会一次性关闭“重新开图时强制刷新”，并将原默认音量 40 降为 20。自定义音量、静音、检测区域和游戏计时参数保留。

“扫描完成”表示生成了可用标注且通过当前画面检查，不代表游戏数据和每个预测百分之百正确。黄色候选状态只提供相近候选的共同信息供参考。

## 自动识别失败时

右键托盘图标，打开“自动运行与检测自检”。“检测自检”显示真实检测状态和最近游戏区域预览。
DAY 提示只在当天开始时出现，平时显示等待是正常情况。

备用框选按钮会在 2 秒后截图，期间请切回游戏并展示相应画面。也保留原版的校准快捷键。
框选后会记录相对于游戏窗口的位置。特殊 UI 比例、HDR、很低血量或非标准地图面板可能仍需要一次校准。

绝招倒计时沿用原版的五种角色支持，需要首次框选绝招图标并绑定游戏中实际使用的绝招键。
“计时纠正”可以直接指定当天、当前阶段与该阶段已过秒数，也可以清理旧状态并开始新局。

## 配置位置

增强版配置保存在 `%APPDATA%\nightreign-overlay-helper-plus`。原版的配置目录保留。
`settings.yaml` 保存原功能设置，`automation.yaml` 保存自动运行、提醒及窗口校准信息。
如测试时设置 `NROH_DATA_DIR` 环境变量，则使用该指定目录。

## 已知边界

地图数据和游戏计时参数来自 v0.10.5，未在线更新游戏数据。自动刷新的是当前画面识别结果。
不能从被背包遮挡的 DAY 提示中推断准确的开局时间；候选无法区分时只显示共同信息。
HDR、游戏设置与特殊地形仍需实机检查。当前不提供路线规划、已探索地点自动推断或实时队友共享。
全程采用窗口位置和截图识别，不读写游戏内存，不自动发送游戏操作。

## 从源码运行和构建

使用 Python 3.13 和项目内虚拟环境，安装 `requirements-lock.txt`。运行 `python launch.py`。
Windows 构建脚本为 `scripts/build_windows.ps1`，使用 PyInstaller `--onedir --windowed`。
测试：`python -B -m unittest discover -s tests -v`。
